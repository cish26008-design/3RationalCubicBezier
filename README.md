# 3RationalCubicBezier
大学の研究で作成した、C++およびOpenGLを用いたベジェ曲線開発ツールです。

## 概要
クリックすることで制御点を任意の位置に置くことができ、４つの制御点からBezier曲線が生成されます。またシェーダプログラムを使用して曲率が単調な領域に色を塗っており、両端点の曲率円と曲率コームの表示を行えます。曲率プロットの表示を行うことで曲率が単調に増加もしくは減少しているかがわかります。
塗られた領域の色にあった制御点をその領域内に動かすことで曲率が単調な曲線が描けます。

##注意
自分の環境に対応して動くように設定しているため、動かす場合は実行ファイルの指定とglmのダウンロードが必要です。
